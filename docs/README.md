## 🚀 빠른 시작

1. **의존성 설치**
   ```bash
   flutter pub get
   ```

2. **코드 생성** (Riverpod 사용 시)
   ```bash
   dart run build_runner build
   ```

3. **앱 실행**
   ```bash
   flutter run
   ```
